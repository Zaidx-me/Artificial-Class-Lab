# 05 — Replit

**Type:** Cloud / browser IDE · **Developer:** Replit

## Install
No installation — web-based.
```
Open https://replit.com  →  sign in / sign up
```

## Setup
- Free tier: create repls, limited agent usage
- Replit Agent (autonomous builder) / Ghostwriter: paid plans from ~$25/mo

## Notes from our install
- Zero setup time (1/5). Everything runs in their cloud container.
- Latency is inherent to a browser IDE (~1 s+ responses in independent tests).
