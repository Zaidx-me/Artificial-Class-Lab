# 10 — Codeium

**Type:** Editor + Extension (autocomplete) · **Developer:** Exafunction / Codeium

## Install
```bash
code --install-extension Codeium.codeium
```
(On Open VSX it is published as the "Windsurf Plugin formerly Codeium" extension.)

## Setup
- Free sign-in (email/Google); no credit card needed
- Unlimited autocomplete; no agent mode

## Notes
- Fast (~40 ms completions) and free, but **completion-only** — cannot autonomously build
  a project. Its real agent features were folded into Windsurf/Devin Desktop.
