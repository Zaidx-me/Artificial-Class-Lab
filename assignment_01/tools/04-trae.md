# 04 — Trae

**Type:** Standalone AI IDE (VS Code fork) · **Developer:** ByteDance

## Install (Arch/CachyOS)
```bash
paru -S --noconfirm trae-bin      # AUR: "The Real AI Engine" (ByteDance)
```
Or download installer: https://trae.ai

- Default models: Claude + GPT; "Toon" agent; BYO API key supported
