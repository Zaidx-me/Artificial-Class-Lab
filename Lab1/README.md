# Lab 1: Introduction to AI and Its Application Using Python

This lab covers the fundamentals of Python programming, including:

## Files

| File | Topic |
|------|-------|
| `01_python_syntax.py` | Basic Python syntax, print statements, comments |
| `02_input_output.py` | User input and output operations |
| `03_multiple_statements.py` | Writing multiple statements on one line |
| `04_indentation.py` | Python indentation rules and best practices |
| `05_reserved_words.py` | Python reserved keywords |
| `06_data_types.py` | Data types: Numbers, Booleans, Strings, Type casting |
| `07_lists.py` | List creation, indexing, and slicing |
| `08_conditionals.py` | Comparison operators and conditional statements |

## How to Run

```bash
python 01_python_syntax.py
python 02_input_output.py
# ... etc
```

## Requirements

- Python 3.6 or higher
